# Entrega del informe: Git y GitHub aplicados a Base de Datos

La investigación se entrega mediante **un único informe en PDF por grupo**. Se puede trabajar de manera individual o en grupos de **hasta 4 integrantes**.

## Formulario de entrega

[Subir el informe de Base de Datos](https://forms.gle/7BQweQHYNGMR93KGA)

Un solo integrante del grupo debe completar el formulario y enviar el archivo. Escriban allí los **nombres y apellidos de todos los integrantes** y el curso y división correspondientes.

## Antes de enviar

- [ ] El PDF se abre correctamente y tiene un nombre identificable, por ejemplo `BD_6-1_Apellido1_Apellido2.pdf`.
- [ ] La portada identifica institución, materia, curso y división, docente, integrantes y fecha.
- [ ] El índice contiene los apartados y los números de página correctos.
- [ ] El informe incluye introducción, desarrollo, ejemplo aplicado a Base de Datos, conclusión y bibliografía con enlaces.
- [ ] El encabezado identifica el trabajo y el curso; el pie contiene la numeración de páginas y la identificación breve del grupo o de la materia.
- [ ] El ejemplo incluye tres cambios concretos y tres mensajes de commit relacionados con esos cambios.
- [ ] El formulario se envía **una sola vez por grupo**.

Revisen la [consigna completa de la investigación](01-Investigacion_Git_y_GitHub_Base_de_Datos.md) antes de realizar la entrega.
