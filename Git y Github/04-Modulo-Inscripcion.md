## Actividad: sistema de login para el módulo de inscripción

**Objetivo:** crear el sistema de inicio de sesión (login) para el módulo de inscripción, siguiendo el tutorial.

### 1. Preparación del entorno

Los primeros minutos del video explican cómo instalar **MAMP o XAMPP** y **MySQL Workbench**.

Si todavía no tienen estas herramientas, comiencen desde el inicio del video y realicen la instalación. **Es necesario tener el entorno instalado y funcionando para poder desarrollar la actividad.**

### 2. Desarrollo de la actividad

Una vez preparado el entorno, sigan el tutorial **a partir del minuto 6:10**, donde comienza el desarrollo que deberán realizar.

Avancen paso a paso y prueben el funcionamiento del login.

**Video tutorial:** [Ver en YouTube](https://youtu.be/v8wMvsdzNHw)

### 3. Entrega del proyecto

Deberán **subir el proyecto a un repositorio de GitHub utilizando Git**, tal como lo hicieron en la **Actividad 2**.

Registren los cambios mediante commits, súbanlos al repositorio y **entreguen el enlace para su revisión**.
